# Michael Wolfenberger — Personal Website & Technical Portfolio

Source code for [michaelwolfenberger.com](https://michaelwolfenberger.com), deployed via GitHub Pages with custom DNS, semantic HTML5, and schema optimization.

## 🚀 Overview
- **Live Site:** [https://michaelwolfenberger.com](https://michaelwolfenberger.com)
- **Architecture:** Static HTML5, CSS3, JSON-LD Schema (`NewsArticle`, `Person`)
- **CI/CD:** Automated GitHub Pages deployment

## 📂 Site Structure
- `index.html` — Homepage, core profile, active projects, and media analysis feed
- `alien-review.html` — Long-form film analysis of Ridley Scott's *Alien (1979)*
- `sitemap.xml` — Search engine sitemap index
